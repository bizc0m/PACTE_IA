# LORE — Index

Référentiel des éléments narratifs et visuels de la Meute. Les badges D7 constituent ici un module de **fiches de compétences de personnages**, et non une certification officielle du Bujinkan.

### D7 — Règles et fonctionnement

- **Neuf positions** : ligne 1 = trois domaines (**Numérique**, **Diplomatie**, **Forces spéciales**) ; lignes 2 et 3 = six niveaux d’essence D7, dont les intitulés peuvent être édités.
- **Progression par compétence** : niveaux 1 à 9 visibles par sous-cases lumineuses ; **niveau 10** = une seule surface pleine sans subdivisions.
- **Luminosité locale** : chaque compétence augmente en intensité avec son niveau, sans modifier les autres cases.
- **Trame blanche** : intensité indépendante, réglable sur dix niveaux.
- **Édition** : clic sur une compétence pour augmenter son niveau ; Maj + clic pour diminuer ; intitulés modifiables dans l’éditeur.
- **Import/export du personnage** : profil JSON ; export de la grille seule aux formats HTML, SVG et PNG ; export des neuf badges individuellement en SVG et PNG via ZIP.
- **Style** : source CRT issue du fichier `crt.css` de Lab0 fourni en référence (phosphore, trame, halos et balayage). Le rendu comporte des adaptations à la matrice D7.
